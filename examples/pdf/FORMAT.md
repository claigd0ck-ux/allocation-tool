# 예치기관 제안서 PDF 표준 양식

PRD 5절 must ①의 "기관이 정해진 형식으로 제시한" PDF의 형식이다. 툴의 PDF 인식(PLAN 작업 13·14)은 이 양식을 기준으로 값을 읽는다.
실제 기관 양식이 이와 다르면 이 문서와 `lib/pdf/parseProposal.ts`를 함께 고친다.

## 항목 (한 줄에 하나, `항목: 값`)

```
예치기관 적립금 상품 제안서
기관명: A은행
평가 점수: 95
현재 예치 잔액: 300억 원
수수료 적용 방식: 구간 전체          ← "구간 전체" 또는 "누진"
[1년물]
상품명: A은행 1년물
금리: 3.500%
수수료: 0억 원 이상 0.150%, 300억 원 이상 0.100%
[3년물]
상품명: A은행 3년물
금리: 3.900%
수수료: 0억 원 이상 0.200%
담당자: 김담당 (02-000-0000)        ← 읽지 않고 저장하지 않는다
```

## 읽는 규칙

- 항목 이름 뒤 `:`(또는 `：`)부터 다음 항목 이름 전까지가 값이다. 줄바꿈·띄어쓰기가 흐트러져도 항목 이름으로 나눈다.
- 금액은 억 원 정수로 읽는다(`1,200억 원`, `1200억원`, `1200억` 모두 같다). `30,000,000,000원`처럼 원 단위면 억 원으로 딱 떨어질 때만 바꾸고, 아니면 값을 넣지 않고 노란색(확인 필요)으로 둔다.
- 금리·수수료율은 % 숫자로 읽는다. 소수점이 쉼표로 적혔거나(`3,500%`) 글자가 섞이면 노란색으로 둔다.
- 항목이 없으면 비워 두고 "누락"으로 표시한다. 추측해서 채우지 않는다.
- `담당자` 등 사람 이름·연락처는 읽지 않는다.
- 글자를 선택할 수 없는 PDF(스캔본)만 AI(OpenAI)로 읽는다. 글자는 있는데 위 항목을 하나도 찾지 못한 PDF는 실무자가 파일마다 동의할 때만 AI로 보낸다.

## 예시 파일

`node scripts/make-example-pdfs.mjs`로 만든다 (숫자는 `examples/cases.json` 예시 1과 같은 가짜 자료).

| 파일 | 내용 |
|---|---|
| `A은행.pdf` ~ `D은행.pdf` | 예시 1의 네 기관, 표준 양식 그대로 (글자 선택 가능) |
| `KB-A은행_이름다름.pdf` | 기관명이 "KB A은행"으로 적힌 A은행 (짝 맞추기 확인용) |
| `C은행_누락.pdf` | "수수료 적용 방식"이 빠진 C은행 (누락 표시 확인용) |
| `D은행_스캔본.pdf` | 종이를 스캔한 것처럼 글자를 그림(이미지)으로만 넣은 D은행 (글자 추출 불가 → AI 인식) |
